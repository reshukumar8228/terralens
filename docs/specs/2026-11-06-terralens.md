## Scientific design
Use the creator's EuroSAT RGB archive, verify its checksum, validate image decoding, hash duplicates and assign anonymous IDs. Never use category paths, class labels, class-balanced sampling or class-informed tuning. Isolate reference labels in an evaluation-only file. Use a seeded 80/20 split. Fit the imputer if needed, numerical scaler and PCA on study rows only. Describe colour, texture and edge features in a deterministic feature dictionary. Compare unscaled/scaled features, colour-only/combined features, K-Means without PCA and PCA retaining 90/95/99% variance. Sweep K 2–15 and seeds in a staged bounded grid. Select on internal evidence, stability and unlabeled patch inspection; freeze selection before opening the label audit. Evaluate held-out patches without refitting. Use a fixed 3,000-patch maximum visual cohort, identical IDs in PCA and t-SNE; measure trustworthiness on a bounded identical subset and reference space. t-SNE perplexity/seed comparisons are recorded studies, not evidence of ground-truth classes. No explained variance for t-SNE, no clustering in its 2D coordinates, no new-upload t-SNE coordinate, no calibrated confidence from centroid distances.

Large genuine image mosaics, linked plots and patch inspector, compact experiment controls, charts and feature profiles. Paper background, forest navigation, restrained amber/teal plotting accents, accessible stable cluster colours, self-hosted typography. No fabricated counters, stock marketing sections, decorative gradients or fake charts. Every control must connect to data or a genuine workflow. Desktop presentation quality and usable mobile navigation. Loading, error, empty, focus and disabled states.

## Architecture
React/TypeScript/Vite frontend; Python/FastAPI API and reusable scikit-learn pipeline. Immutable generated study bundles and fitted artifacts; runtime experiments stored in local SQLite and disk, explicitly temporary on free hosting. One bounded job at a time. Serve the built frontend through FastAPI in production. Raw dataset is downloaded by script, excluded from Git/ZIP; selected anonymous preview patches and the compact reference study are included so the application can run immediately. Download is required to reproduce the complete data study. API receives bounded parameters and validates uploads before decoding. Browser exports and generated documents use measured results and IDs.
